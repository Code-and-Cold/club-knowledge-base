Дан массив целых чисел `arr`. Отсортируйте массив, выполнив серию **переворотов**.

При одном перевороте мы выполняем следующие действия:

- Выбираем целое число `k`, где `1 <= k <= arr.length`.
- Меняем местами элементы в подмассиве `arr[0...k-1]` (**нумерация с нуля**).

Например, если `arr = [3,2,1,4]` и мы выполняем переворот с выбором `k = 3`, мы меняем местами элементы в подмассиве `[3,2,1]`, так что после переворота с `k = 3` массив `arr` будет выглядеть как `[1,2,3,4]`.

Верните *массив из* `k` *значений, соответствующих последовательности переворотов, которые сортируют* `arr`. Любой допустимый ответ, при котором массив будет отсортирован за `10 * arr.length` переворотов, будет засчитан как правильный.

**Пример 1:**

```
Входные данные: arr = [3,2,4,1]
Выходные данные: [4,2,4,3]
Объяснение: 
Мы переворачиваем 4 блина, используя значения k 4, 2, 4 и 3.
Исходное состояние: arr = [3, 2, 4, 1]
После первого переворота (k = 4): arr = [1, 4, 2, 3]
После второго переворота (k = 2): arr = [4, 1, 2, 3]
После третьего переворота (k = 4): arr = [3, 2, 1, 4]
После четвертого переворота (k = 3): arr = [1, 2, 3, 4], то есть в отсортированном порядке.
```

**Пример 2:**

```
Входные данные: arr = [1,2,3]
Выходные данные: []
Пояснение: входные данные уже отсортированы, поэтому ничего переворачивать не нужно.
Обратите внимание, что другие ответы, например [3, 3], также будут засчитаны.
```

**Ограничения:**

- `1 <= arr.length <= 100`
- `1 <= arr[i] <= arr.length`
- Все целые числа в `arr` уникальны (то есть `arr` представляет собой перестановку целых чисел от `1` до `arr.length`).
