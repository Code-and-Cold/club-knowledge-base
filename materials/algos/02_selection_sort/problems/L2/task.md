Вам задан целочисленный массив `nums`.

За один ход вы можете выбрать один элемент из `nums` и изменить его на **любое значение**.

Верните *минимальную разницу между наибольшим и наименьшим значением `nums` **после выполнения не более трех ходов***.

**Пример 1:**

```
Ввод: nums = [5,3,2,4]
Вывод: 0
Пояснение: Мы можем сделать не более 3 ходов.
На первом ходу измените 2 на 3. цифры станут [5,3,3,4].
На втором ходу измените 4 на 3. цифры станут [5,3,3,3].
На третьем ходу измените 5 на 3. Цифры станут [3,3,3,3].
После выполнения 3 ходов разница между минимальным и максимальным значением будет равна 3 - 3 = 0.
```

**Пример 2:**

```
Ввод: nums = [1,5,0,10,14]
Вывод: 1
Объяснение: мы можем сделать не более 3 ходов. 
 На первом ходу меняем 5 на 0. nums становится [1,0,0,10,14]. 
 На втором ходу меняем 10 на 0. nums становится [1,0,0,0,14]. 
 На третьем ходу меняем 14 на 1. nums становится [1,0,0,0,1]. 
 После 3 ходов разница между минимальным и максимальным значениями составляет 1 – 0 = 1. 
 Можно доказать, что за 3 хода разницу в 0 получить невозможно. 
```

**Пример 3:**

```
Входные данные: nums = [3,100,20]
Выходные данные: 0
 Объяснение: мы можем сделать не более 3 ходов. 
 На первом ходу меняем 100 на 7. nums становится [3,7,20]. 
 На втором ходу меняем 20 на 7. nums становится [3,7,7].
На третьем шаге меняем 3 на 7. nums становится [7,7,7].
После трех шагов разница между минимальным и максимальным значениями равна 7 - 7 = 0.
```

**Ограничения:**

- `1 <= nums.length <= 10<sup>5</sup>`
- `-10<sup>9</sup> <= nums[i] <= 10<sup>9</sup>`
