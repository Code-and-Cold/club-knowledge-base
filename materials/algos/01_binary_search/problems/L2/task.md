Коко любит есть бананы. Есть `n` кучек бананов, в `i-той` кучке `piles[i]` бананов. Охранники ушли и вернутся через `h` часов.

Коко может сама выбирать, сколько бананов она съест за час — `k`. Каждый час она выбирает какую-нибудь кучку бананов и съедает `k` бананов из этой кучки. Если в кучке меньше `k` бананов, она съедает все бананы из этой кучки и больше не ест в течение этого часа.

Коко любит есть медленно, но все же хочет успеть съесть все бананы до возвращения охранников.

Верните *наименьшее целое число* `k`, *при котором она сможет съесть все бананы за* `h` *часов*.

**Пример 1:**

```
Входные данные: piles = [3,6,7,11], h = 8
Выходные данные: 4
```

**Пример 2:**

```
Входные данные: piles = [30,11,23,4,20], h = 5
Выходные данные: 30
```

**Пример 3:**

```
Входные данные: piles = [30,11,23,4,20], h = 6
Выходные данные: 23
```

**Ограничения:**

- `1 <= piles.length <= 10 в четвёртой степени`
- `piles.length <= h <= 10 в девятой степени`
- `1 <= piles[i] <= 10 в девятой степени`
