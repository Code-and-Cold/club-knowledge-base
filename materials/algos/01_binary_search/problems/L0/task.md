Дан массив целых чисел `nums`, отсортированный по возрастанию, и целое число `target`. Напишите функцию для поиска `target` в `nums`. Если `target` существует, верните его индекс. В противном случае верните `-1`.

Вы должны написать алгоритм со сложностью выполнения `O(log n)`.

**Пример 1:**

```
Входные данные: nums = [-1,0,3,5,9,12], target = 9
Выходные данные: 4
Пояснение: 9 есть в nums, его индекс равен 4
```

**Пример 2:**

```
Входные данные: nums = [-1,0,3,5,9,12], target = 2
Выходные данные: -1
Пояснение: 2 нет в nums, поэтому возвращаем -1
```

**Ограничения:**

- `1 <= nums.length <= 10 в четвёртой степени`
- `-10 в четвёртой степени < nums[i], target <= 10 в четвёртой степени`
- Все целые числа в `nums` **уникальны**.
- `nums` отсортированы в порядке возрастания.
