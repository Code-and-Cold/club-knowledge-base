В данном репозитории представлены три задачи L[0-2] взятые с сайта LeetCode - 704, 34 и 875 соответственно.

В каждой папке L[0-2] лежат файлы:

- `task.md`: описание задачи.
- `main.py`: ваше решение.
- `test.py`: тесты.

Чтобы проверить решение, используйте команду `python test_search.py` (для модуля unittest, работает без дополнительной настройки).
Чтобы проверить решение с более качественным выводом, используйте команду `pytest` (требуется установка pytest в venv или на системном уровне).
