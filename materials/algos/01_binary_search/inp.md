# Проблема и решение

Предположим, вы ищете фамилию человека в телефонной книге (какая древняя технология!).
Она начинается с буквы "К". Конечно, можно начать с самого начала и перелистывать страницы, пока вы не доберетесь до буквы "К".
Но для ускорения поиска лучше раскрыть книгу на середине: ведь буква "К" должна находиться где-то ближе к середине телефонной книги.

# Формулировка алгоритма

Таким образом можно составить алгоритм:

1. Берём элемент из середины книги/фрагмента книги и сравниваем его с искомым.
2. Сразу отбрасываем ту половину, где нужного элемента точно нет.
3. Повторяем с оставшейся половиной — снова делим её пополам.

Это и называется двоичным поиском. Важное ограничение данного подхода - исходный массив должен быть отсортирован.

# Код и задание

```python
def binary_search(arr, target):
    low, high = 0, len(arr) - 1

    while low <= high:
        mid = low + (high - low) // 2

        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1

    return -1
```

# Пример выполнения кода

```python
numbers = [2, 7, 13, 19, 25, 34, 37, 46, 58, 72]
result = binary_search(numbers, 37)
print(f"Found at index: {result}")  # → 6
print(binary_search(numbers, 99))   # → -1
```
