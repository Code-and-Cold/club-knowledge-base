# EXPERIMENTAL

Тестовый вариант one-shot генерации презентации. Работает приемлимо, но нужна доводка результата генерации и ручное создание ассетов.

Для создания презентации по главе книги:

1. Получите фрагмент книги (например так: `pdftk Грокаем_алгоритмы_2.pdf cat 49-69 output selection_sort.pdf`).
2. Поместите его сюда, заменив `source*.pdf`.
3. Отправьте все файлы в данной папке, кроме README.md в llm, отключите поиск в сети.
4. Используете вывод в Kova. Отредактируйте размеры изображений, добавьте служебные слайды (обратная связь, практикум и т.д.). Создайте необходимые изображения и поместите их в папку assets в директории выходного файла.
5. (Optional) вроде неплохо получается, если после этого попросить "Вставь speaker notes в соответствии с текстом главы и освещая непокрытые в презентации аспекты.". При включении этого пункта в one-shot prompt всё ломается.
