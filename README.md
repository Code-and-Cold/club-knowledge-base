# База знаний клуба Code and Cold

Целью клуба является весёлое и полезное времяпрепровождение посредством практических занятий по специальностям it сферы.

Вход на мероприятия свободный, участие тоже.

Если хотите следить за новостями клуба, переходите по ссылке: https://vk.ru/cold_code

Также у нас есть свой сайт: https://code-n-cold.ru

## Расписание и формат

Встречи клуба проходят по вторникам. Занятия проходят в соответствии с набором рубрик.
Длительность занятий может варьироваться, со средним в 1-1.5 ч.

### Ближайшие мероприятия

- 26.10.27 Алгоритмический вторник: зачем нужен индекс? Грокаем двоичный поиск. (Example, WIP)
- 26.11.03 Изучаем X за час: вводный курс по VMWare VirtualBox, основы виртуализации. (Example, WIP)

## Рубрики

Набор форматов (именумый рубриками) которые проводятся клубом.

### Алгоритмический вторник

Сочетающая в себе теорию и практику встреча, направленная на улучшение навыков спортивного программирования участников.

### Изучаем X за час

Практикоориентированная встреча для желающих получить вводные знания, полезные советы и практику по использованию конкретного инструмента/технологии.

## Ответственные

- Чат ВК (способ связи): нет.
- Страница клуба ВК: Настя
- Мероприятия клуба: ответственный за мероприятия, по умолчанию капитан (Иван).
- Этот репозиторий: Николай
