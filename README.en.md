# Code and Cold Club knowledge Base

The goal of the club is to have a fun and useful pastime through practical classes in the IT field.

Admission to the events is free, and participation is also free.

If you want to follow the club's news, follow the link: https://vk.ru/cold_code

We also have our own website: https://code-n-cold.ru

## Schedule and format

Club meetings are held on Tuesdays. Classes are held according to a set of headings.
The duration of classes may vary, with an average of 1-1.5 hours.

### Upcoming events

- 10/26/27 Algorithmic Tuesday: understanding binary search.
- 11/26/03 Learning X in an hour: Pandoc + beamer as a tool for generating presentations from md.

## Categories

A set of formats (called categories) that are hosted by the club.

### Algorithmic Tuesday

A meeting combining theory and practice aimed at improving the participants' sports programming skills.

### Learning X in an hour

A practice-oriented meeting for those who want to get introductory knowledge, useful tips and practice on using a specific tool/technology.
